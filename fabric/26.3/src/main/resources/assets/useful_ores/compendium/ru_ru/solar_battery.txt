Перезаряжаемая батарея для [печи Solarite](Utility/Solarite Furnace) и других совместимых машин. Сохраняет заряд между использованиями.

Зарядите её с помощью солнечной системы мода, затем установите в совместимую машину. Также нужна для создания [вагонетки с батареей Solarite](Utility/Solarite Battery Minecart).
