Première étape pour fabriquer le bâton météorique. Placez un noyau de météorite entre deux bâtons de Blaze, à la verticale, pour obtenir un éclat.

Combinez ensuite l’éclat avec du souffle de dragon pour créer un noyau de météorite volatile. Les noyaux se trouvent dans les météorites écrasées ; les bâtons de Blaze et le souffle de dragon sont des objets vanilla.
