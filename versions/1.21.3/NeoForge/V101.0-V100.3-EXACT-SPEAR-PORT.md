# V101.0 — V100.3 exact spear client-port reset

Replaced the previous NeoForge spear presentation/movement layer with the V100.3 Fabric implementation as the source of truth.

Porting rule: preserve V100.3 animation equations, anchors, timing, raw-hand-state model, movement-factor algorithm, and jab/swing timing. Only platform integration is adapted: NeoForge event bus and vanilla custom-payload transport.

Validated against supplied Minecraft 1.21.10 Mojang mappings for:
- ItemInHandRenderer#renderArmWithItem
- ItemInHandRenderer#applyItemArmTransform / applyItemArmAttackTransform / renderItem
- LocalPlayer#modifyInput / canStartSprinting / vehicleCanSprint / hasEnoughFoodToSprint
- ArmedEntityRenderState#extractArmedEntityRenderState
- ItemInHandLayer#submitArmWithItem
- HumanoidModel#setupAttackAnimation / setupAnim
- LivingEntity#getCurrentSwingDuration

The old BackportSpearAnimations, HeldItemRenderer, ItemModelResolver, and ItemStackRenderState spear rendering path were removed to prevent competing transforms.
