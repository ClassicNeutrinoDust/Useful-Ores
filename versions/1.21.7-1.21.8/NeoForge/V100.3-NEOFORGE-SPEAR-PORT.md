# Useful Ores — NeoForge 1.21.10 V100.3 Spear Port

The NeoForge spear subsystem has been replaced with a direct behavioral port of the proven Fabric V100.3 implementation.

## Replaced spear gameplay
- Server-authoritative charged/kinetic contact processing from `Item#onUseTick`.
- Pre-collision client velocity sampling only; client target UUID is ignored for damage authority.
- 1.21.11-style attack range: normal 0.4–4.5 blocks; creative 0.0–6.5 blocks; 0.25-block hitbox margin.
- 4.6 blocks/second kinetic eligibility using full relative-motion magnitude, with directional projected speed for damage scaling.
- Contact-loss-aware 10-tick cooldown: one continuous contact cannot repeatedly damage the same entity.
- Dedicated LMB jab packet/path with attack-speed cooldown.
- Charged spear movement/sprint preservation while using the spear.
- Spear does not function as a block-mining weapon through the normal attack path.
- Existing V100.3 animation curves and first-/third-person spear transforms ported to the NeoForge classes.

## NeoForge adaptation
- Fabric networking replaced with NeoForge play payload registration.
- Fabric client tick sync replaced with NeoForge client tick events.
- Fabric item implementation replaced with `BackportSpearItem` extending NeoForge/Mojang `Item`.
- Existing NeoForge spear registration is retained, but the old spear combat implementation and old spear living-entity hooks were removed.
- V100.3 spear sounds and sound registrations were added.

## Validation status
Source-level port and structural checks were completed in this environment. Gradle/NeoForge compilation was not available here, so the first local validation command is:

`gradle clean build`

No claim of a successful NeoForge build is made until that command is run locally.
