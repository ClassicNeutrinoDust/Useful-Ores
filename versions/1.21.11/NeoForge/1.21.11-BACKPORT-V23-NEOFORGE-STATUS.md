# Useful Ores — Minecraft 1.21.11 NeoForge Backport V23

## Purpose
This batch ports the remaining NeoForge source from the 26.1.2 API surface toward the actual 1.21.11 API, using the working Fabric 1.21.11 implementation and the 1.21.11 NeoForge/Minecraft mappings as references.

## Main fixes

### Identifier rename
Minecraft 1.21.11 uses `Identifier` instead of `ResourceLocation` throughout the API. All remaining NeoForge source references were migrated, including JVM descriptors in the minecart renderer mixin.

### SavedData
1.21.11 uses `DimensionDataStorage` rather than 26.1's `SavedDataStorage`. All affected data classes were migrated. `SavedDataType` ids were restored to the 1.21.11 string-id form and the nullable data-fix parameter was restored where required.

Affected systems include:
- bioluminescent blocks
- blastproof blocks
- chest locks
- phosgene powder
- enderium pending launches
- wireless relay network
- Ancient Pedestal map assignments

### NeoForge block break events
Migrated 26.1 `BreakBlockEvent` references to 1.21.11 `BlockEvent.BreakEvent`.

### 1.21.11 render API
- `CameraRenderState` package corrected to `net.minecraft.client.renderer.state.CameraRenderState`.
- Projectile renderers were restored to the 1.21.11 `SubmitNodeCollector#submitBlock` path rather than 26.1's `BlockModelResolver` / `BlockModelRenderState` path.
- `ColoredFlameParticle` restored to `getLightColor` + `LightTexture.lightCoordsWithEmission`.
- Solarite Furnace lighting uses `LightTexture.pack`.
- Arcanite XP jar uses `RenderTypes.itemEntityTranslucentCull`.
- Compendium uses `GuiGraphics.renderItem` / `renderItemDecorations`.
- Super Beacon uses the 1.21.11 `BlockState#getLightBlock()` form.

### GeckoLib 5.4.5
The four GeckoLib block renderers use the raw `GeoBlockRenderer` compatibility form required by the 1.21.11 GeckoLib 5.4.5 API.
