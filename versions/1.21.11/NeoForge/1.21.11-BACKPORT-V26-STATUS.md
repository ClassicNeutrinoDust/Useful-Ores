# Useful Ores 1.21.11 NeoForge V26

## Root-cause fix
The NeoForge dev-client crash after V25 was caused by AncientPedestalMapLootFunction.init() calling Registry.register on BuiltInRegistries.LOOT_FUNCTION_TYPE from the mod constructor after registries were frozen. V26 replaces that unsafe direct registration with NeoForge DeferredRegister using Registries.LOOT_FUNCTION_TYPE and registers it on the mod event bus.

This removes the registry-freeze crash before client resource/model initialization.

The V25 source tree is otherwise preserved.
