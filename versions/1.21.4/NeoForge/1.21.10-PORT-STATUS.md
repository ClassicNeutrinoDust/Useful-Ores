# Useful Ores 2.1.7 — Minecraft 1.21.10 Port

This tree contains both loader-specific ports of Useful Ores:
- `Fabric-1.21.10` — Fabric for Minecraft 1.21.10
- `NeoForge-1.21.10` — NeoForge for Minecraft 1.21.10

## Port basis
The source was taken from the 1.21.11 backport and reverse-migrated to the 1.21.10 API surface.

Key compatibility changes include:
- Minecraft `Identifier` API restored to `ResourceLocation` and corresponding factory/method names.
- 1.21.10-compatible resource/model format versions.
- Fabric Loader/Fabric API targets changed to 0.18.1 / 0.138.4+1.21.10.
- NeoForge target changed to 21.10.64.
- GeckoLib changed to the 1.21.10 `5.3-alpha-3` builds for both loaders.
- Fabric and NeoForge mod metadata dependency ranges updated for the 1.21.10 GeckoLib build.

## Validation
The build could not be executed in this environment because the required Minecraft, loader, and GeckoLib Gradle artifacts are not locally cached and outbound dependency downloads are unavailable.

Run `gradle clean build` inside each loader directory with the matching 1.21.10 GeckoLib JAR in `libs/`.
