# V99.2 — Spear kinetic-charge fix

## Root cause

V99.1 reconstructed charge speed from position samples during `END_SERVER_TICK`.
Minecraft 1.21.11 `KineticWeapon` instead uses the entity known movement, which is
derived from movement delta and projected onto the view vector. The charge damage
condition uses the resulting relative closing speed.

## Fix

`SpearChargeCombat.knownSpeed()` now uses `Entity#getDeltaMovement()` as the
primary signal, scaled by 20 to blocks/second, with a position-delta fallback only
when movement delta is zero. This preserves the official kinetic-speed semantics
without changing the 4.6 blocks/second spear damage threshold.

The rest of V99.1's working jab/animation architecture is unchanged.
