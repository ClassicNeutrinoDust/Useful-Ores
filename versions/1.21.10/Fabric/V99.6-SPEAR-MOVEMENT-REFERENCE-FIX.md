# V99.6 — movement reference fix

The V99.5 movement hook could still leave Minecraft's generic held-item slowdown active because it used a named selector with `require=0` and returned the raw input vector.

This version replaces intermediary `method_67270(Vec2f)` with `require=1` and reproduces the full vanilla movement calculation, skipping only the generic `0.2x` held-item slowdown when the main-hand item is a spear. It also replaces the previous unconditional `canSprint()` hook with the nuanced sprint gates from the supplied Accurate Spears 1.21.10 reference jar.

Sources used:
- supplied Accurate Spears 2.2 1.21.10 jar, `SpearMovementMixin` bytecode
- Yarn mappings for `LocalPlayer.method_67270` / `method_74047`
