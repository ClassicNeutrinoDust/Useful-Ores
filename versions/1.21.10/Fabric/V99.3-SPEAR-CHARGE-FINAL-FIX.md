# V99.3 – final kinetic charge correction

## Root causes fixed

1. The kinetic server loop previously ran at END_SERVER_TICK. By then a sprinting/flying player could have had its forward delta changed by collision/friction, so the measured charge speed was too late. It now runs at START_SERVER_TICK.
2. Charge contact used a camera-ray/eye-distance test that could report no target even when the player physically collided with the mob. It now uses an attack-range-style AABB proximity test with a forward cone and line-of-sight check.
3. The previous minimum-distance gate was removed for kinetic contact; physical overlap is valid.
4. Creative spear reach is 7.5 blocks, matching the 1.21.11 spear range.
5. The client now bypasses the 1.21.10 generic `isUsingItem()` movement/sprint branch for spears at `aiStep`, plus the existing lower-level hooks. This prevents spear charge from slowing walking or creative flying.

## Reference basis

NeoForged's 1.21.10 -> 1.21.11 primer documents `UseEffects(canSprint=true, speed multiplier=1.0)` and that `KineticWeapon#damageEntities` is executed server-side every use tick. The same primer documents spear `ATTACK_RANGE` and the kinetic relative-speed threshold.
