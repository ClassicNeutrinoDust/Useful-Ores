V100.9 - NeoForge 1.21.10 runtime mixin fix

Root cause from crash report: MixinHeldItemRendererSpear targeted renderFirstPersonItem, but Minecraft 1.21.10 ItemInHandRenderer exposes renderArmWithItem with the exact signature:
renderArmWithItem(AbstractClientPlayer,float,float,InteractionHand,float,ItemStack,float,PoseStack,SubmitNodeCollector,int)

Changed only the mixin target from renderFirstPersonItem to renderArmWithItem. Other V100.3 spear behavior remains unchanged.
